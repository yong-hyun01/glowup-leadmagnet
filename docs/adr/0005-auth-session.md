# ADR 0005. 운영자 인증: 서명 세션 쿠키 + bcrypt

- 상태: 채택
- 날짜: 2026-10-22

## 맥락
"인증한 운영자만 관리자 기능과 신청자 데이터를 볼 수 있어야 한다" 는 요구사항이 있습니다. 운영자는 소수(과제에서는 1명)이며 회원가입·권한 등급은 범위 밖입니다.

## 결정
- 운영자 계정은 `operators` 테이블에 bcrypt 해시로 저장하고, 시드 스크립트(`python -m app.seed`)가 환경변수로 초기 계정을 만듭니다. 가입 API 는 두지 않았습니다.
- 로그인 성공 시 `itsdangerous` 로 서명·타임스탬프된 토큰을 **쿠키**(`Path=/admin`, `HttpOnly`, `SameSite=Strict`, 운영 환경에서 `Secure`)로 발급합니다. 서버 세션 저장소는 두지 않습니다(stateless).
- 관리자 API 는 라우터 단위 의존성(`get_current_operator`)으로 보호하고, 관리자 화면은 미인증 시 로그인 페이지로 리다이렉트합니다.
- CSRF 는 `SameSite=Strict` 로 차단합니다. 관리자 API 는 모두 JSON 또는 multipart 이며 같은 사이트의 fetch 로만 호출됩니다.

## 고려했으나 채택하지 않은 안
- **JWT Bearer 헤더.** 브라우저 저장 위치(localStorage) 문제와 로그아웃 처리 때문에 쿠키보다 복잡해집니다. 동일 출처 관리자 화면에는 쿠키가 더 안전하고 단순합니다.
- **서버 세션 테이블.** 강제 로그아웃이 필요해지면 추가할 예정입니다.

## 결과
- 세션 만료는 8시간(`SESSION_MAX_AGE_SECONDS`)입니다. 비밀번호 변경 시 기존 세션 무효화는 지원하지 않습니다(`SECRET_KEY` 교체로 전체 무효화는 가능합니다).

# ADR 0006. 채널별 배포 링크와 채널 귀속

- 상태: 채택
- 날짜: 2026-10-22

## 맥락
운영자는 인스타그램·X·유튜브·스레드용 링크를 만들어 배포하고, 각 채널의 성과를 봐야 한다. SNS 프로필·게시물 링크는 보통 한 줄 URL 하나만 허용되며 UTM 파라미터가 잘리는 경우가 있다.

## 결정
- 폼 × 채널당 **짧은 토큰 링크** `/l/{token}` 을 하나 발급한다(`distribution_links`, `(form_id, channel)` 유니크). 같은 채널을 다시 요청하면 기존 링크를 돌려준다.
- `/l/{token}` 은 `/f/{slug}?l={token}` 으로 302 리다이렉트한다. 방문 기록과 프레임 URL, 제출 본문까지 토큰이 전달되어 **방문과 신청 모두** 채널이 귀속된다.
- 채널은 enum(`instagram`, `x`, `youtube`, `threads`)으로 고정한다. 과제가 네 채널을 명시했고, 자유 문자열이면 오타로 채널이 쪼개진다.
- 제출 시 `link_token` 이 다른 폼의 토큰이면 무시하고 `direct` 로 기록해 채널 데이터 오염을 막는다.

## 고려했으나 미채택
- **UTM 쿼리(`?utm_source=instagram`).** 링크가 길고 SNS 에서 잘리거나 사용자가 수정하기 쉽다. 토큰 링크가 더 짧고 위변조에 강하다.
- **채널별 폼 복제.** 같은 HTML 을 네 번 등록해야 해서 운영 부담이 크다.

## 결과
- 채널을 추가하려면 enum 과 마이그레이션 변경이 필요하다. 의도적인 제약이다.
